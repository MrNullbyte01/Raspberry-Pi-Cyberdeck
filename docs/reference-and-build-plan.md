# Cyberdeck Reference Analysis & Build Plan

## Main inspiration: Tommi Laukkanen's Cyberdore

This project takes inspiration from Tommi Laukkanen's Raspberry Pi cyberdeck work. The original Cyberdore write-up describes an early build based on a Raspberry Pi 3 Model B+, while the later Cyberdore 2064 write-up documents a move to a Raspberry Pi Zero W to reduce power consumption and create a compact portable computer.

These are reference designs, not my own original design. This repository is for documenting my own implementation, decisions, changes, and test results.

## What to study in the reference

- Compact layout and ergonomics
- Display and keyboard integration
- Portable power and cable routing
- Enclosure construction and serviceability
- Trade-offs between Raspberry Pi models and power consumption
